# SPEC

作業名: **kawaii-site**
状態: 設計固め完了 / 実装前
最終更新: 2026-10-19

## 1. コンセプト

「情報を読むポートフォリオ」ではなく、**開いた瞬間に可愛さへ入るサイト**。
オリジナルキャラクターが案内役で、画面遷移そのものがコンテンツになる。

- 方向性: ふわふわ・もふもふ・きゃわわ
- 主役: オリジナルキャラクターとワイプ遷移
- 情報量: 少ない。1画面に3〜5個で十分
- やらないこと: ソシャゲの機能、絵本モチーフ、長い文章、スクロールする長いページ

### 役割分担

| 要素 | 質感 |
| --- | --- |
| ワイプ | グラフィック。直線的、フラット、白フチ、パステル |
| キャラ | ふわふわ。丸い、柔らかい、影は1段 |
| 背景 | 静か。クリーム色＋浮遊する小さな図形 |
| UI | 丸いカード、太めの輪郭、押せる感 |

全部をふわふわにするとぼやける。ワイプとUIで締めて、キャラで緩める。

## 2. 画面構成

1画面完結。スクロールしない。下部タブで切り替える。

| タブ | 内容（最小） |
| --- | --- |
| ホーム | 名前、一言、キャラの挨拶、最新ブログ1件 |
| わたし | プロフィールカード、すきなもの3つ |
| つくる | 作品カード2〜3枚 |
| すき | テト、アニメ、旅、音楽などのステッカー |
| つながる | SNSリンク、Contact |

- タブは5つ。多すぎるとワイプが忙しい。
- 各ページは「見出し＋キャラ＋カード数枚」で完結させる。
- 詳細ページは作らない。カードはその場で少し広がる程度。
- ホームの最新ブログは外部リンクでよい。

### レイアウト

- モバイル: 全画面。下部タブは親指の届く位置。
- デスクトップ: 中央に 480〜560px の縦長シェル。左右は背景とキャラの余白。
- 上下に固定バーを置く場合も、ワイプは全画面を覆う。

## 3. ビジュアル

### 形

- 角丸 24〜32px
- 輪郭線 2px（黒ではなく温かい濃茶）
- 影は `0 6px 0 rgba(74, 59, 59, 0.12)` のような硬めの落ち影
- 半透明のツヤ、点描（ハーフトーン）を少量
- ステッカー風の白フチ

### 色（候補・未確定）

| 名前 | ベース | メイン | サブ | 差し色 |
| --- | --- | --- | --- | --- |
| いちごミルク | `#FFF7F2` | `#FFB3C7` | `#B8E6D9` | `#FF8FA3` |
| ソーダ | `#F7FBFF` | `#A9DCF5` | `#FFE08A` | `#B8E6D9` |
| よるのラベンダー | `#2E2A4A` | `#C9B6E4` | `#F7B2D9` | `#FFF4E6` |

- 文字色は純黒を避け、濃茶または濃い藍。
- タブごとにテーマ色を1つ持たせる。ワイプの帯の色もそれに合わせる。

### フォント

- 見出し: Zen Maru Gothic または M PLUS Rounded 1c
- 本文: 上記の本文ウェイト、または Noto Sans JP
- アクセント: DotGothic16（使いすぎない）
- サブセット化して自前ホストする。

## 4. 画面遷移

詳細は [MOTION.md](MOTION.md)。

- 3本の帯によるワイプ（A案）
- 8度傾ける。進行方向で反転
- 速→遅→速。合計0.7秒
- 中央でキャラが登場し、ページ名の看板を持つ
- 看板と新ページの見出しを同じ位置・同じ色でつなぐ

## 5. キャラクター

- オリジナルキャラクターを外部に依頼する前提。
- 発注仕様は [CHARACTER.md](CHARACTER.md)。
- 納品前はプレースホルダー（丸い塊＋耳＋目）で実装する。
- パーツ分けされていると、耳・しっぽ・腕・まばたきが動かせる。
- 遷移用に「看板を持つ」「しゃがむ」ポーズが必要。

## 6. コンテンツ

最小構成で成立させる。文章は各ページ3行まで。

- ホーム: 名前（mofh / Beans）、一言、時間帯で変わる挨拶
- わたし: 一人称、誕生日、居住地、学生、すきなもの
- つくる: comic-wiki、JTale、プリント管理アプリなど
- すき: テト、アニメ（百合）、山梨・長野・富士山、音楽
- つながる: X 3つ、note、ブログ、VRChat、Contact

## 7. 技術（提案・未確定）

- Vite + React + TypeScript
- Motion（framer-motion）
- CSS は素の CSS ＋ CSS 変数（Tailwind でも可）
- React Router か、5画面用の小さな view state
- 画像は WebP / AVIF（アルファ対応）、表示サイズの2倍まで
- Cloudflare Pages に静的デプロイ
- 解析は軽量なもの（必要な場合のみ）

### 遷移の実装方針

- `TransitionProvider` が `idle / cover / hold / reveal` を持つ
- 遷移中はルート変更をロックし、全面が覆われた瞬間に差し替える
- 次ページの画像はホバー／タッチ開始時に先読み
- キャラはルーターの外に置き、遷移中もアンマウントしない
- 連打はロック。遷移中のタップは早送り

## 8. アクセシビリティ

- `prefers-reduced-motion`: 120ms のフェードのみ
- 遷移後は新しい見出しにフォーカスを移す
- タブはキーボードで移動できる
- 色だけで状態を伝えない
- 効果音は初期オフ。トグルを用意する
- 遷移はスキップ可能にする
