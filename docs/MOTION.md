# MOTION

画面遷移の設計。実装の基準になる値はここに集約する。
状態: 設計確定 / ワイプと構図を実装済み（音・フォームは未実装）

## 1. 基本原則

- 遷移は **速→遅→速**。イーズインアウト（遅→速→遅）の逆。
- 入りは勢いよく、中央でためて、抜けは一気に。
- 中央の「ため」は可愛さの置き場所。ここだけは削らない。
- 動かすのは `transform` と `opacity` だけ。
- ワイプはグラフィック、キャラはふわふわ。質感を混ぜない。

## 2. タイムライン

合計 1.11秒。値は初期案で、実機で調整する。

| 時間 | フェーズ | 出来事 |
| --- | --- | --- |
| 0–380ms | cover | 3本の帯が入る。40ms ずつズラす |
| 380–780ms | hold | 全面が覆われる。中央にキャラ |
| 400ms | hold | キャラが中央にポンと出る（0.7→1.05→1.0、260ms） |
| 470ms | hold | 看板が -8度→0度で出る（220ms） |
| 470–690ms | hold | 看板を掲げてまばたき1回 |
| 780ms | hold | キャラがしゃがんで中央に吸い込まれる |
| 780–1110ms | reveal | 帯が抜けて新ページが見える |
| 800ms | reveal | 看板と同じピンクを見出しに引き継ぐ（位置のモーフは v2） |
| 1110ms | idle | 完了。フォーカスを新見出しへ |

- 帯の stagger は 40ms。3本目が終わるのが 380ms。
- 「ため」は最短 120ms まで短縮可。初回や連続遷移で調整する。

## 3. イージング

| フェーズ | 値 | 理由 |
| --- | --- | --- |
| cover | `cubic-bezier(0.22, 1, 0.36, 1)` | 速く入って減速 |
| hold | 停止（背景のストライプだけ微速） | 間を作る |
| reveal | `cubic-bezier(0.64, 0, 0.78, 0)` | ゆっくり動き出して加速 |
| キャラ登場 | spring `{ stiffness: 300, damping: 20 }` | ぽん、と跳ねる |
| 看板 | spring `{ stiffness: 260, damping: 18 }` | 少しだけ overshoot |

実装は **CSS の `transition` / `@keyframes`**。帯は `transform` の transition、キャラは 260ms の keyframes（0.7 → 1.05 → 1.0）、看板は 220ms の少し overshoot する easing。遷移レイヤーはこれで十分で、バンドルも増えない。Motion はページ内の小さな動き（ホバーなど）に残す。

## 4. ワイプの形

- 帯は3本。単色＋白い 2〜3px の先端フチ。
- 太さは不均等（太・中・細 = 3:2:1 くらい）。
- 傾きは **8度**。静的で、動かさない。
- 進行方向で傾きを反転する。
  - 右から左へ: `skewX(-8deg)`
  - 左から右へ: `skewX(8deg)`
- 最後の帯だけ、同系色の細いストライプを薄く敷く。止まったときに「ストライプの画面」に見える。
- 抜けるときは逆順（3本目から先に抜ける）にズラす。1本あたり 250ms + 40ms ズレで、reveal 全体は 330ms。
- 帯は画面幅 130〜140%。`inset` を広げて、傾きで隙間が出ないようにする。

### 方向

| 遷移 | 方向 | 傾き |
| --- | --- | --- |
| タブ（後ろ→前） | 右から左 | `-8deg` |
| タブ（前→後ろ） | 左から右 | `+8deg` |
| 詳細へ（将来用） | 下から上 | `skewY(-6deg)` |
| 戻る（将来用） | 上から下 | `skewY(6deg)` |

## 5. 中央のキャラ

- 遷移に出るのは**ちびキャラ**だけ。立ち絵は遷移に使わない。
- 画面中央に、下からせり上がるのではなく **その場にポンと出る**。
- 0.7倍 → 1.05倍 → 1.0倍。足元に小さな星か雲を4〜6個散らす。
- 足元に薄い楕円の影を置く。浮いて見えないように。
- 看板は片手で掲げる。文字は1語（「つくる」「すき」など）。
- 看板の色は**全タブ共通のメイン色**（`--color-main`）。新ページの見出しも同じ色にする。タブごとに色を分けない（SPEC §3）。
- 抜けるときは、しゃがんで小さくなり中央に吸い込まれる。看板だけ一瞬残す。

### 看板と見出しのつなぎ

- v1: 看板が消えるのと同じタイミングで、新ページの見出しが元の位置に現れる。**色（ピンク）を共有**してつながって見せる。位置のモーフはしない。
- v2: `layoutId` で看板から見出しへモーフする。
- まず v1 で成立させる。v2 は精度が上がってから。

## 6. 実装

### 状態

```
idle → cover → hold → reveal → idle
```

- `navigate(next)` が呼ばれたら `cover` を開始。
- `cover` 完了時にルートを差し替える。
- `hold` でキャラと看板を出す。
- `reveal` 開始時にキャラを引っ込める。
- `reveal` 完了で `idle`。

### ガード

- 遷移中は新しい `navigate` を受け付けない。
- cover / hold / reveal の間は `html` に `overflow: hidden` を付けてスクロールを止める（`idle` に戻ったら解除）。
- 遷移中のタップは「早送り」。`hold` を 120ms に縮める。
- キーボードは `Esc` / `Enter` で早送り。タップできない環境でも待たされない。
- 早送り中もフォーカスは奪わない。遷移中の全面レイヤーは `pointer-events: none`（早送り用の1枚だけ受ける）。
- 同じタブへの遷移は何もしない。
- 戻る操作は方向を反転する。

### URL と履歴

- `navigate(next)` は遷移の開始だけ。URL は触らない。
- **cover 完了**（画面が完全に覆われた瞬間）に、コンテンツの差し替えと `history.pushState` を同時に行う。見た目と URL がずれない。
- 同じパスへの遷移は push しない。
- `popstate`（戻る／進む）は push せず、方向に応じたワイプで表示を合わせる。
- **cover 中**（まだ push していない）に `popstate` が来たら、その遷移は取りやめる。push せず、表示だけを `popstate` の位置に合わせる。
- **push 後**（hold / reveal）に `popstate` が来たら、今の遷移を最後まで走らせてから、最新の位置へ逆方向ワイプ。連続で来たときは最後の1つだけ使う。
- 方向はタブの並び順（ホーム 0 … つながる 4）の差分で決める。戻る／進むも同じ規則。
- 直リンク・リロードはワイプなしで即表示。
- 未知のパスは `/` に `replaceState`。
- コンテンツの差し替え（cover 完了）で `window.scrollTo(0, 0)`。戻る／進むも同じ。
- ページごとのスクロール位置復元は v1 ではしない。

### 先読み

- タブの `pointerenter` / `touchstart` で次ページの画像を先読み。
- `cover` と `hold` の間は画像デコードの待ち時間に使う。
- 間に合わない場合は「待つ」演出に切り替える。キャラが時計を見る、ため息をつくなど。

### パフォーマンス

- 帯は3枚まで。増やさない。
- `will-change: transform` は遷移中だけ付ける。
- `filter: blur()` をアニメーションさせない。必要な場合は事前にぼかした画像を使う。
- 影は静的な画像か `box-shadow` の固定値。動かさない。
- キャラ画像は表示サイズの2倍まで。WebP / AVIF。
- 粒子は最大12個。Canvas より DOM で足りる。

### アクセシビリティ

- `prefers-reduced-motion: reduce` では 120ms のフェードのみ。キャラの登場も省略。
- 遷移後、新ページの `h1` に `tabindex="-1"` でフォーカス。
- スクロールロック中もキーボード操作を奪わない（`overflow: hidden` だけ）。
- 効果音は初期オフ。設定は `localStorage` に保存。

## 7. 効果音（確定）

BGM は無し。**効果音のみ**。初期オフ。

音源ファイルは持たず、**Web Audio API で合成する**（AudioContext + OscillatorNode / NoiseBuffer + GainNode のエンベロープ）。
素材探し・ライセンス・追加リクエストを無くすため。4音だけなので合成で足りる。

| タイミング | 音 | 作り方の目安 |
| --- | --- | --- |
| cover 開始 | 短い「シュッ」 | ノイズ + highpass を 120ms で減衰 |
| キャラ登場 | 「ポン」 | サイン波 600→900Hz の短いピッチ上げ + 速い減衰 |
| 看板 | 「ペタ」 | 短いノイズバースト + 低めの三角波を 60ms |
| reveal | 「シュッ」を逆再生風に | ノイズを逆エンベロープ（だんだん強く→切る） |

- 初期オフ。右上のトグルでON。
- 初回のONで `AudioContext` を生成する（自動再生制限のため、クリック起点で `resume()`）。
- 音量は小さめ。連打で鳴りすぎないように間引く（同じ音は 80ms 以内なら鳴らさない）。
- 画面が `visibilitychange` で隠れたら `suspend()`。

## 9. オープニング（案・未確定）

タブ移動のワイプとは別枠。初回だけの短い演出で、ワイプは使わない。

| 時間 | 出来事 |
| --- | --- |
| 0–400ms | 背景に小さな星が3〜5個ふわっと出る |
| 300ms | キャラが中央にポン（0.7→1.05→1.0） |
| 500ms | サイト名が下から 8px 上がってフェードイン |
| 900–1300ms | キャラとタイトルが少し上に抜け、ホームの中身がフェードイン |

- 合計 1.3秒。タップ／キーで即終了。
- 2回目以降は出さない（`sessionStorage`）。直リンク・リロードでも出さない。
- reduced motion では出さない。
- 効果音は初期オフなので、ON にしている人だけ「ポン」が鳴る。
- サイト名が決まったら差し込む。決まるまでは仮テキスト。

```ts
export const OPENING = {
  total: 1300,
  starsIn: 0,
  characterIn: 300,
  titleIn: 500,
  exit: 900,
} as const;
```

## 10. ページ内の動き（2026-10-20 追加）

スクロールする構成になったので、ページ内の動きをここにまとめる。ワイプとは独立。

| 場所 | 動き | 値 |
| --- | --- | --- |
| ホームのワードマーク | 1文字ずつ下から上がってフェード。ドットは最後にポン | 600ms / 60ms stagger / 120ms delay。ドットは 640ms 遅延 / 300ms |
| ホームのキャラ | ゆっくり上下（`chibi-bob`） | 4.5s / -6px |
| ナビの現在地 | ピンクのピル。動きなし | — |
| カードのホバー | 2px 浮く | 160ms ease-out |
| 見出し | ワイプ後にピンクのハイライトが引き継がれる（v1） | — |

- アニメーションは `transform` と `opacity` だけ。`filter` / `box-shadow` は動かさない。
- ワードマークは `prefers-reduced-motion` では stagger せず、最初から表示する。
- スクロールに応じた出現アニメーションは v1 では入れない（読みづらくなるため）。
- ページ内リンクのスムーズスクロールも入れない（遷移の速さと喧嘩する）。
