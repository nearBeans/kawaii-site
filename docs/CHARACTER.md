# CHARACTER

オリジナルキャラクターの発注仕様。
状態: ドラフト / **未発注**
最終更新: 2026-10-20

## 1. 方針

- サイトの主役は**ちびキャラ**。遷移の中央もページ常駐も、基本はちび1種で通す。
- ちびの**ポーズ差分**を数枚そろえれば成立する。動きは CSS / Motion で付ける。
- 立ち絵は「納品物として出てきたら使う」扱い。必須にしない。無くてもサイトは成立する。
- 発注は「ちび＋差分」を主、立ち絵は余力があれば追加で。

## 2. 用途

- 画面遷移の中央にポンと出て、ページ名の看板を持つ
- 各ページに1ポーズだけ常駐する
- まばたき、耳、しっぽ、腕を軽く動かす（パーツ分けがある場合）

## 3. 世界観

- ふわふわ・もふもふ・きゃわわ
- パステル、丸い、柔らかい
- 手描きの温かさ。線は太めで統一
- 影は1段だけ。塗りはフラット寄り
- 背景は透明。サイトのクリーム色（`#FFF7F2`）に馴染む

## 4. 必要なもの

### ちびキャラ（必須）

| ポーズ | 用途 | 優先度 |
| --- | --- | --- |
| 立ち（通常） | 各ページの常駐 | 必須 |
| 看板を持って掲げる | 遷移の中央 | 必須 |
| しゃがむ／小さくなる | 遷移の退場 | 必須 |
| 手を振る | ホーム、外部リンク | 推奨 |
| びっくり | 連打や効果音のリアクション | 任意 |

表情差分は目と口だけで足りる。

- 通常
- にこにこ
- びっくり
- 眠り

### 立ち絵（任意）

- 各ページの常駐を、ちびより大きく見せたい場合のみ
- 「通常」と「手振る」の2枚で足りる
- ちびと同一キャラであること（色・線の太さ・比率の印象を揃える）

### パーツ分け（理想）

PSD のレイヤーを以下に分ける。

- 頭
- 前髪
- 耳（左右）
- 体
- 腕（左右）
- 手（左右）
- しっぽ
- 目（開き／半目／閉じ）
- 口（閉じ／開き／にっこり）
- 眉
- 頬

パーツ分けがあれば、まばたき・耳ピク・しっぽ・腕振りができる。
1枚絵しか難しい場合は、ポーズ差分で対応する。

## 5. 納品形式

- **透過 PNG ＋ レイヤー分け PSD**（ちび・立ち絵それぞれ）
- ちび: 長辺 1200px 程度（遷移表示 480px の2倍）
- 立ち絵: 長辺 2000px 程度
- 背景なし
- 基準点は足元中央。トリミング位置を全ポーズで揃える
- レイヤー名は英語で分かりやすく
- 可能なら WebP も

## 6. 色

- ベースはパステル。サイトの配色「いちごミルク」に合わせる。
  - ベース `#FFF7F2` / メイン `#FFB3C7` / サブ `#B8E6D9` / 差し色 `#FF8FA3`
- 文字色に使う濃茶（`#4A3B3B` 前後）と相性の良い色。
- 彩度を上げすぎない。蛍光色は避ける。

## 7. NG

- 線が細すぎる（小さいサイズで消える）
- 写実的な陰影
- 背景に溶ける薄い色
- ポーズごとにサイズ・位置がバラバラ
- 透過抜け、半透明のゴミ
- ちびと立ち絵で別人に見える
