# CHARACTER

オリジナルキャラクターの発注仕様ドラフト。
状態: ドラフト / 依頼前に確定させる

## 1. 用途

- Webサイト「kawaii-site」の案内役
- 画面遷移の中央に登場し、ページ名の看板を持つ
- 各ページに1ポーズだけ常駐する
- まばたき、耳、しっぽ、腕を軽く動かす

## 2. 世界観

- ふわふわ・もふもふ・きゃわわ
- パステル、丸い、柔らかい
- 手描きの温かさ。線は太めで統一
- 影は1段だけ。塗りはフラット寄り
- 背景は透明。サイトのクリーム色に馴染む

## 3. 必要なもの

### ポーズ

| ポーズ | 用途 | 優先度 |
| --- | --- | --- |
| 立ち（通常） | 各ページの常駐 | 必須 |
| 看板を持って掲げる | 遷移の中央 | 必須 |
| しゃがむ／小さくなる | 遷移の退場 | 必須 |
| 手を振る | ホーム、外部リンク | 推奨 |
| 走る | 任意の遊び | 任意 |
| 寝る／座る | 無操作時 | 任意 |

### 表情

- 通常
- にこにこ
- びっくり
- しょんぼり
- 眠り
- 口を開ける（喋る）

### パーツ分け（理想）

PSD のレイヤーを以下に分ける。

- 頭
- 前髪
- 耳（左右）
- 体
- 腕（左右）
- 手（左右）
- しっぽ
- 目（開き／半目／閉じ）
- 口（閉じ／開き／にっこり）
- 眉
- 頬

パーツ分けがあれば、まばたき・耳ピク・しっぽ・腕振りができる。
1枚絵しか難しい場合は、ポーズ差分で対応する。

## 4. 納品形式

- 透過 PNG または PSD
- 長辺 2000px 程度（Web表示の2倍）
- 背景なし
- 基準点は足元中央。トリミング位置を全ポーズで揃える
- レイヤー名は英語で分かりやすく
- 可能なら WebP も

## 5. 色

- ベースはパステル。サイトの配色候補に合わせる。
- 文字色に使う濃茶（`#4A3B3B` 前後）と相性の良い色。
- 彩度を上げすぎない。蛍光色は避ける。

## 6. NG

- 線が細すぎる（小さいサイズで消える）
- 写実的な陰影
- 背景に溶ける薄い色
- ポーズごとにサイズ・位置がバラバラ
- 透過抜け、半透明のゴミ

## 7. 依頼文テンプレート

> Webサイト用のオリジナルキャラクターを描いていただきたいです。
> 用途は、画面遷移の中央に登場してページ名の看板を持つ演出と、各ページへの常駐です。
> そのため、以下のポーズとパーツ分けをお願いしたいです。
>
> - ポーズ: 立ち、看板持ち、しゃがみ（小さくなる）、手振り
> - 表情: 通常、にこにこ、びっくり、しょんぼり、眠り、口開け
> - パーツ: 頭、前髪、耳、体、腕、手、しっぽ、目、口、眉、頬
> - 納品: 透過PNG（長辺2000px程度）＋パーツ分けPSD
> - 基準点: 足元中央。全ポーズで位置を揃えてください
>
> 世界観は「ふわふわ・もふもふ・きゃわわ」で、パステル中心、線は太め、影は1段でお願いします。
